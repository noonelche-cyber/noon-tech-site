Supprimer vos données KARD°ASH

Mis à jour le 8 octobre 2026.

Sur votre téléphone Android

  1. Pour retirer une Kard, utilisez sa commande de suppression. Si elle est placée dans la corbeille, elle peut encore être restaurée ; supprimez-la définitivement depuis la corbeille si vous ne voulez plus la conserver.
  2. Pour effacer l’ensemble du stockage local, y compris les documents privés conservés, ouvrez les réglages Android → Applications → KARD°ASH + → Stockage → Effacer les données. Le nom exact de ces commandes dépend de votre téléphone. Cette opération efface les Kards, réglages et fichiers internes ; elle est irréversible sans sauvegarde.
  3. Supprimez séparément les sauvegardes .kardash et les fichiers exportés, sur le téléphone ou dans les services où vous les avez enregistrés. Les copies déjà envoyées à d’autres personnes restent chez ces destinataires.

Facebook et Instagram

La connexion Meta n’est pas encore activée dans la version Android 369. Aucun jeton de compte Meta n’est actuellement conservé par cette version. Les publications importées par lien, partage ou capture sont des données locales : supprimez les Kards ou effacez les données de l’application comme décrit ci-dessus.

Si vous avez accordé une autorisation à KARD°ASH lors d’un test de connexion, vous pouvez retirer cette autorisation dans les paramètres des applications ou intégrations de votre compte Meta. Retirer une autorisation n’efface pas automatiquement les copies déjà importées sur votre téléphone.

Données envoyées à NOON Tech

Pour demander la suppression d’un e-mail ou d’autres données que vous avez transmises à NOON Tech, écrivez à noontech.hola@gmail.com avec l’objet « Suppression des données KARDASH ». Précisez le compte ou l’adresse e-mail concernés et les données à supprimer. N’envoyez jamais de mot de passe, code de connexion ou jeton Meta. Nous confirmerons le traitement de votre demande et vous signalerons toute information nécessaire ou limite applicable.

NOON Tech ne peut pas supprimer à distance les données présentes uniquement sur votre appareil ou chez un autre destinataire.
